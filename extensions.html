Extensions

Extensions are data

Extensions change how every service behaves — blocking, banners, routing. Each one is a signed JSON file: filter lists and addresses, never code.

How it works
01

Signed registry

The list is signed with an Ed25519 key built into the app. Anything that does not match the signature is rejected.

02

Data, not code

A content blocker is a set of filter lists, a proxy is an address. There is no field an extension could use to run a script.

03

Yours to switch

Turn an extension off or remove it at any time. The proxy applies only to the services you pick.
