# vertex-site

Landing page for [Vertex](https://kvlsx.github.io/vertex-site/), published with
GitHub Pages from the `main` branch.

Downloads live in [kvlsx/vertex-releases](https://github.com/kvlsx/vertex-releases/releases);
the page reads the latest tag and date from the GitHub API, so a new release
shows up here without the page being touched.

The Vertex source itself is private.
